# SUPER GAME BOY++ by ZJSS

The pixel-art icons from the Silky Remix SUPER GAME BOY++ theme, on their own: the consoles, every
Onion app and the RetroArch cores, with the theme's selected versions. ZJSS drew the app and core
icons and the consoles the base set lacks; the other console icons are the set below.
Theme: https://github.com/zakijss/SuperGameBoy
